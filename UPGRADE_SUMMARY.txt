Run All Tests:
  $ pytest tests/ -v
  ✅ Expected Result: 42 passed

Access API Docs:
  • Interactive Swagger UI: http://localhost:9000/docs
  • ReDoc Alternative: http://localhost:9000/redoc

Chat with AI (curl example):
  $ curl -X POST http://localhost:9000/api/ai/chat \
    -H "Content-Type: application/json" \
    -d '{"message": "Recommend clubs for me", "context": "career"}'

Stream AI Response:
  $ curl -N http://localhost:9000/api/ai/chat/stream \
    -H "Content-Type: application/json" \
    -d '{"message": "Help me...", "context": "career"}'

Get Mentor Plan:
  $ curl -X POST http://localhost:9000/api/ai-pro/mentor-plan \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -d '{"target_role": "AI Engineer"}'

💡 KEY INSIGHTS & LEARNINGS
================================================================================

1. Cognitive Reasoning Layer
   - LLMs are powerful, but guided reasoning > raw completion
   - Thinking traces make AI decisions interpretable
   - Fallback engines ensure reliability

2. Multi-Agent Design
   - Specialization beats generalization for domain expertise
   - Agents need tool access to be truly autonomous
   - Fallback agents work well for offline scenarios

3. Testing Strategy
   - 100% test coverage of critical paths
   - In-memory databases make tests fast
   - Fixture-based testing improves maintainability

4. API Design
   - Streaming endpoints scale better than polling
   - SSE (Server-Sent Events) is simpler than WebSockets for this use case
   - Stateful conversations need session tracking

5. Fallback Engineering
   - Every external dependency needs a fallback
   - Rule-based systems can be surprisingly effective
   - Local computation > distant API calls for latency
